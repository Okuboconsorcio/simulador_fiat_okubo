# Simulador Fiat Okubo

Aplicativo Streamlit público e independente para simular crédito, lance, parcela e cenários de contemplação.

## Arquivos

- `app.py`: interface do simulador.
- `calculator.py`: fórmulas da simulação.
- `requirements.txt`: dependências para o Streamlit Cloud.

## Publicação no Streamlit

1. Acesse o Streamlit Community Cloud.
2. Clique em Create app.
3. Selecione o repositório `Okuboconsorcio/simulador_fiat_okubo`.
4. Use a branch principal e o arquivo `app.py`.
5. Escolha o subdomínio desejado.

Este app não usa Supabase, Google Sheets ou dados do portal principal.
