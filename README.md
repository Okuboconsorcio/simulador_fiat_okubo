# Simulador Fiat Okubo

Aplicativo Streamlit publico e independente para simular credito, lance, parcela e cenarios de contemplacao.

## Arquivos

- `app.py`: interface do simulador.
- `calculator.py`: formulas da simulacao.
- `requirements.txt`: dependencias para o Streamlit Cloud.

## Publicacao no Streamlit

1. Acesse o Streamlit Community Cloud.
2. Clique em Create app.
3. Selecione o repositorio `Okuboconsorcio/simulador_fiat_okubo`.
4. Use a branch principal e o arquivo `app.py`.
5. Escolha o subdominio desejado.

Este app nao usa Supabase, Google Sheets ou dados do portal principal.
